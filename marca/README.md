# Marca FactPOS

- `factpos.svg` · ícono principal (app, escritorio, pestaña)
- `factpos-simbolo.svg` · símbolo sin fondo, para fondos oscuros
- `factpos-maskable.svg` · ícono para instalar en Android (zona segura)
- `factpos-mono.svg` · un solo color (ticket térmico, sellos, documentos)
- `factpos.ico` · Windows, 10 tamaños (16 a 256 px)

Idea: la **F** de Factura dentro de un anillo (la facturación electrónica es el corazón
del sistema). El anillo de cuatro colores representa el sistema camaleón; dentro de la
aplicación, el anillo puede tomar el color de la marca de cada cliente.

Colores: Tinta `#0E1B26` · Turquesa `#2DD4BF` · Azul `#60A5FA` · Lima `#A3E635` · Ámbar `#FBBF24`
